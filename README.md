 MakeMyTrip Analytics Dashboard (Power BI Project)

 Project Overview
 This project is an interactive Power BI dashboard designed to analyze travel booking data inspired by platforms like MakeMyTrip.  
 It provides insights into customer behavior, booking trends, revenue performance, and travel demand patterns.

 The goal of this project is to demonstrate data analytics, visualization, and business intelligence skills.


## 🛠 Tools & Technologies
- Power BI (Data Visualization)
- Microsoft Excel (Data Source)
- DAX (Calculated Measures & KPIs)
- Power Query (Data Cleaning & Transformation)

---

## 📈 Dashboard Highlights
- 📌 Total Bookings & Revenue KPIs
- 📌 Monthly & Seasonal Travel Trends
- 📌 Top Performing Travel Destinations
- 📌 Customer Booking Behavior Analysis
- 📌 City-wise Performance Breakdown
- 📌 Interactive Filters (Date, City, Category)
- 📌 Dynamic Charts & Visual Storytelling

---

## 🔍 Key Business Insights
- Peak booking activity observed during holiday seasons
- Certain destinations consistently generate higher revenue
- Customer demand varies significantly across months
- Metro cities contribute major share of bookings
- Travel patterns help identify growth opportunities
